对外 API(让别的程序调用本工具)

本工具可作为一个 OpenAI 兼容的视频网关:外部程序按下面格式提交,本工具用当前激活的服务商去生成。设置鉴权 Key 后,调用需带 Authorization: Bearer <key>(留空=不鉴权,仅限本机使用)。

提交(异步,推荐): 
curl -X POST http://127.0.0.1:5321/v1/video/generations \
  -H "Authorization: Bearer <key>" -H "Content-Type: application/json" \
  -d '{"model":"kling-v2-master","prompt":"a cat surfing","duration":5,"size":"1280x720"}'
# → {"task_id":"...", "status":"queued"}
# 轮询:
curl http://127.0.0.1:5321/v1/video/generations/<task_id> -H "Authorization: Bearer <key>"
# 完成后返回 {"status":"completed","url":"http://127.0.0.1:5321/outputs/xxx.mp4"}
也兼容 OpenAI Sora 风格:POST /v1/videos → GET /v1/videos/{id} → GET /v1/videos/{id}/content(二进制 mp4)。图生视频:在请求里加 "image":"https://...jpg" 或 data URI。
